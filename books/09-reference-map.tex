\section{检查证明时的五个问题}
\begin{enumerate}
\item 测试空间是什么？要求共同紧支集，还是全空间带权衰减？
\item 配对是否线性？是否混入了 Hilbert 内积的复共轭？
\item 对偶运算由哪个测试函数映射的转置得到？该映射是否连续？
\item 移动导数、极限或积分时，支集和半范数是否有统一控制？
\item 唯一性和稳定性在哪个解空间与数据拓扑中成立？
\end{enumerate}

\section{进一步扩充的路径}
本稿已完成分布专题的基础、主要运算及模型应用。若将全书扩为完整泛函分析教材，可在本专题之前插入赋范空间、Banach 空间三大定理、Hilbert 空间与算子理论等分部；本专题之后可继续加入紧算子谱论、无界算子与半群、核空间、Schwartz 核定理、Paley--Wiener 定理、椭圆正则性以及一般广义本征展开。此处只列阅读方向，不以空章节替代正文。
